# 公务英语AI陪练

面向英语底子差的员工、针对**口语对话式考核**的线上练习网页。把考核里固定的几十个短句，
通过「三关训练法」练成条件反射——听辨 → 跟读 → 模拟考，配生句本、掌握度、间隔重复。

> 当前内容为**占位演示版**：句子和音频是示例（酒店前台、客户服务两个场景），
> 用于验证产品流程。真实考核资料到位后，按下方「换真实资料」流程替换即可。

## 三关训练法

| 关卡 | 练什么 | 怎么练 |
|---|---|---|
| 第一关 · 听辨 | 听懂考官问题 | 系统扮演考官随机发问（语音播报），选出问题的中文意思 |
| 第二关 · 跟读 | 张口 + 发音 | 标准音频 → 跟读录音 → 回放对比（支持慢速版） |
| 第三关 · 模拟考 | 真实压力测试 | 随机抽题、限时应答、自动判分（iPhone 无语音识别时自动降级为录音自查） |

贯穿机制：**换说法**（考官会换个问法，练"听懂一类"而不是"背死一句"）、
**生句本**（答错的句子自动进复习队列）、**掌握度进度条**（陌生 → 听过 → 能读 → 能答）。

## 目录结构

```
公务英语AI陪练/
├── index.html       应用本体（一般不用动）
├── data.js          培训资料 ← 换真实资料只改这个文件
├── gen_audio.py     音频生成脚本（微软神经语音 edge-tts）
├── README.md        本说明
└── audio/           预生成 MP3 + manifest.json 对照表
```

## 本地运行

直接把 `index.html` 拖进浏览器，或用本地服务器：

```bash
cd 公务英语AI陪练
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

## 换真实资料（三步）

1. **改 `data.js`** —— 按现有格式填真实句子（每条：考官问 q / 问题中文 qz /
   员工答 a / 答案中文 az / 换说法 variants / 信号词 key）
2. **跑生成脚本**（自动增量，已有句子跳过）：

   ```bash
   pip install edge-tts          # 首次
   python gen_audio.py           # 生成新句子的音频 + 重写 manifest
   ```

3. **重新发布**（或直接打开本地文件生效）

应用代码只认 `manifest.json` 对照表，不认句子本身——句子从 16 句扩到 500 句，
代码一行都不用动，只是 audio/ 目录变大（约 25KB/句）。

## 音色

| 角色 | 音色 | 说明 |
|---|---|---|
| 考官（问题） | `en-US-GuyNeural` | 沉稳男声 |
| 员工（应答） | `en-US-JennyNeural` | 自然女声，另生成慢速跟读版 |

想换音色改 `gen_audio.py` 顶部的 `VOICE_Q` / `VOICE_A` 即可（edge-tts 支持十几种英文音色）。

## 技术栈

- 纯前端单页应用，零后端、零云服务成本
- 音频：edge-tts（微软神经语音）预生成 MP3，播放时优先本地音频，
  缺失句子自动回退浏览器语音合成（功能不断档）
- 录音：浏览器 MediaRecorder（全平台）；语音识别：Chrome/Edge 原生支持，
  iPhone Safari 无识别时自动降级为录音回放自查
- 进度存储：localStorage
